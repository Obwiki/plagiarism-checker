# Scientific PDF Plagiarism Checker (JavaScript)

Локальный веб-проект для оценки **текстового сходства** научной работы в PDF с набором PDF-источников.

## Что умеет

- загружает проверяемую научную работу в PDF;
- извлекает текст из PDF;
- сравнивает его со всеми PDF в `reference-pdfs/`;
- считает совпадение по 7-словным шинглам;
- дополнительно ищет похожие предложения;
- показывает общий процент совпадений и условную «оригинальность»;
- показывает вклад каждого источника и похожие фрагменты;
- сохраняет JSON-отчёты в `reports/`.

## Важно

Это **не официальный сервис Антиплагиат/Turnitin**. Программа может обнаружить только те заимствования, источники которых находятся в вашей локальной базе `reference-pdfs`.

Для полноценного поиска по интернету/академическим индексам требуется подключение внешнего поискового или библиографического API и соблюдение условий его использования. Алгоритм проекта при этом можно оставить как второй этап проверки найденных документов.

PDF-сканы без текстового слоя не поддерживаются базовой версией: для них нужен OCR (например, Tesseract).

## Требования

- Node.js 18+
- npm

## Запуск

```bash
npm install
npm start
```

Откройте:

```text
http://localhost:3000
```

## Как пользоваться

1. Скопируйте PDF-источники, с которыми хотите сравнивать работу, в папку:

```text
reference-pdfs/
```

2. Запустите проект.
3. Откройте веб-интерфейс.
4. Выберите научную работу в PDF.
5. Нажмите **«Проверить работу»**.

## API

### Статус базы

```http
GET /api/status
```

### Проверка PDF

```http
POST /api/check
Content-Type: multipart/form-data
pdf=<file.pdf>
```

Пример через curl:

```bash
curl -F "pdf=@work.pdf" http://localhost:3000/api/check
```

## Как считается процент

Текст нормализуется, стоп-слова частично исключаются, затем строятся шинглы по 7 значимых слов.

Для каждого источника рассчитываются:

- `containment` — какая доля шинглов проверяемой работы найдена в источнике;
- `jaccard` — пересечение шинглов относительно объединения;
- похожие предложения по Dice coefficient.

Общий процент — доля уникальных шинглов проверяемой работы, найденных хотя бы в одном PDF локальной базы. Это предотвращает простое суммирование процентов по нескольким источникам.

## Что можно добавить дальше

- OCR для сканов;
- интеграцию с Crossref / OpenAlex / Semantic Scholar для поиска метаданных и потенциальных источников;
- подключение разрешённого поискового API для поиска фрагментов в интернете;
